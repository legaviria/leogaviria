🧱 Minecraft + Python: Bloques y Decisiones Condicionales

Modifica la variable ambiental y observa cómo el condicional if - elif - else decide qué bloque y color colocar.

Mundo Minecraft: Servidor 15.235.56.59
from mcpi.minecraft import Minecraft
mc = Minecraft.create("15.235.56.59", 8180)
x, y, z = mc.player.getTilePos()
temperatura = 28
if temperatura >= 30:
    mc.setBlock(x+1, y, z, 35, 14) # Rojo
elif temperatura >= 20:
    mc.setBlock(x+1, y, z, 35, 1) # Naranja
elif temperatura >= 10:
    mc.setBlock(x+1, y, z, 35, 5) # Lima
else:
    mc.setBlock(x+1, y, z, 35, 11) # Azul
28 °C
Evaluación Lógica: temperatura = 28 ➔ temperatura >= 20 es True (bloque naranja).
Bloque Colocado: Lana Naranja (ID: 35, Data: 1) Coordenadas: (x+1, y, z)
