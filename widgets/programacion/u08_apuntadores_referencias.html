📍 Punteros Explícitos (C/C++) vs Referencias Transparentes (Python)

Entiende cómo Python abstrae la gestión física de memoria para garantizar seguridad y evitar fugas.

Característica C / C++ (Punteros) Python (Referencias)
Manipulación Directa de direcciones físicas (&x, *ptr) Transparente y automática mediante nombres de variable
Aritmética Permitida: ptr++ avanza N bytes Prohibida: No existe aritmética de punteros
Gestión de Memoria Manual (malloc / free, new / delete) Automática (Garbage Collector + Conteo de referencias)
Riesgos Comunes Segmentation fault, punteros colgantes (dangling), fugas (leaks) Inexistentes; solo referencias cíclicas gestionadas por el GC
💡 Conclusión Conceptual: En Python, "todo es un objeto y las variables son etiquetas". Cuando escribes x = 42, no estás reservando una casilla donde 'x' es el contenedor del 42, sino creando un objeto entero en el Heap y asociando la etiqueta 'x' a dicho objeto. La función integrada id(x) permite consultar la dirección interna en memoria.
