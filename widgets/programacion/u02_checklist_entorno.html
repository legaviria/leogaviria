🛠️ Lista de Comprobación: Configura tu Entorno

Verifica paso a paso que tu estación de desarrollo esté 100% lista para programar

0 de 5 tareas completadas (0%)

1. Instalar Python 3 y agregar al PATH

Descarga el instalador oficial y marca la casilla obligatoria: "Add python.exe to PATH".

python --version  ➔ Python 3.11+

2. Instalar Visual Studio Code

Descarga e instala el editor de código ligero y modular para tu sistema operativo.

code .  ➔ Abre VS Code en la carpeta actual

3. Instalar extensión oficial de Python (Microsoft)

Abre el panel de extensiones (Ctrl+Shift+X) y busca "Python" de Microsoft para autocompletado y depuración.

ms-python.python & Pylance

4. Crear estructura de carpeta del proyecto y archivo .py

Crea una carpeta de trabajo ordenada y un archivo llamado main.py o app.py.

print("¡Hola Mundo!")

5. Ejecutar en la Terminal Integrada

Abre la terminal integrada (Ctrl+ñ) y ejecuta tu script con el comando correspondiente.

python main.py  ➔ ¡Hola Mundo!
🎉 ¡Felicitaciones! Tu entorno de Python y VS Code está listo para construir proyectos profesionales.
