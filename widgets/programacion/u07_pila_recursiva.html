📚 Pila de Llamadas (Call Stack) en Recursividad: Factorial(4)

Observa el apilamiento de marcos de activación hasta el caso base y el posterior desapilamiento.

Código Python:
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
print(factorial(4))
