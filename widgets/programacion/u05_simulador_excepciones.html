🛡️ Simulador de Excepciones: try, except, else, finally

Selecciona un escenario de entrada para observar el control de flujo seguro.

1. Bloque try
a = int(entrada_a)
b = int(entrada_b)
resultado = a / b
2. Bloque except
except ZeroDivisionError:
    print("No divide entre 0")
except ValueError:
    print("Número inválido")
3. Bloque else (Si no hubo error)
print("Cálculo exitoso:", resultado)
4. Bloque finally (Siempre se ejecuta)
print("Cerrando recursos y conexión")
