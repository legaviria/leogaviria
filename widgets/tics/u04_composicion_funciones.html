Composición de Funciones: (g ∘ f)(x) = g(f(x))

Flujo de datos encadenado: Conjunto A → f(x) → Conjunto B → g(y) → Conjunto C

Conjunto A x = 3
f(x) = 2x
Conjunto B f(3) = 6
g(y) = y + 5
Conjunto C 11
(g ∘ f)(x) = g(2x) = 2x + 5
Traza: Para x = 3: f(3) = 6; g(6) = 6 + 5 = 11.
Nota didáctica: La composición no es necesariamente conmutativa: (f ∘ g)(x) = 2(x + 5) = 2x + 10 ≠ 2x + 5.
